## 重构前端目录

### 1. 前端目录结构（合并关联性强，明确接口管理）


```
frontend/
├── public/                    # 静态资源根目录
│   ├── index.html            # 主页面骨架（<50行）
│   ├── login.html            # 登录页面骨架（<50行）
│   ├── 404.html              # 404页面
│   ├── service-worker.js     # Service Worker主文件
│   ├── manifest.json         # PWA清单
│   ├── css/
│   │   ├── core/            # 核心样式
│   │   │   ├── base.css     # 重置+基础样式
│   │   │   ├── layout.css   # 布局样式
│   │   │   └── theme.css    # 主题变量
│   │   ├── components/      # 组件样式（按功能合并）
│   │   │   ├── common.css   # 通用组件（按钮、卡片、表单）
│   │   │   ├── layout.css   # 布局组件（侧边栏、头部）
│   │   │   ├── editor.css   # 编辑器相关
│   │   │   └── modal.css    # 所有弹窗样式
│   │   └── pages/           # 页面级样式
│   │       ├── dashboard.css
│   │       └── login.css
│   ├── js/
│   │   ├── app.js           # 应用入口（<100行）
│   │   ├── config.js        # 配置文件（API端点、常量）
│   │   ├── api/             # API接口管理（与后端一一对应）
│   │   │   ├── index.js     # API统一导出
│   │   │   ├── auth.js      # 认证相关接口
│   │   │   ├── notes.js     # 笔记相关接口
│   │   │   ├── categories.js # 分类接口
│   │   │   └── sync.js      # 同步接口
│   │   ├── core/            # 核心模块
│   │   │   ├── router.js    # 路由管理
│   │   │   ├── store.js     # 状态管理
│   │   │   ├── offline.js   # 离线管理（合并了缓存、网络检测、同步）
│   │   │   └── utils.js     # 工具函数
│   │   ├── pages/           # 页面逻辑
│   │   │   ├── DashboardPage.js  # 看板页面（合并了多个相关组件）
│   │   │   ├── LoginPage.js
│   │   │   └── SettingsPage.js
│   │   └── components/      # 可复用组件
│   │       ├── Layout/      # 布局组件
│   │       │   ├── Sidebar.js
│   │       │   ├── Header.js
│   │       │   └── Footer.js
│   │       ├── Editor/      # 编辑器组件
│   │       │   ├── NoteEditor.js
│   │       │   └── NoteList.js
│   │       ├── Modals/      # 弹窗组件
│   │       │   ├── BaseModal.js
│   │       │   └── modals.js  # 所有弹窗注册
│   │       └── Charts/      # 图表组件
│   │           └── StatsChart.js
│   └── assets/
│       └── ...（不变）
└── wrangler.toml

```

🔄 接口对应关系示例

前端 frontend/public/js/api/目录结构：

```
api/
├── index.js          # 统一导出所有API
├── auth.js          # 对应后端 /api/auth/*
├── notes.js         # 对应后端 /api/notes/*
├── categories.js    # 对应后端 /api/categories/*
└── sync.js          # 对应后端 /api/sync/*

```
